# 🥄 FollowCook

Мобильное приложение для Android, в котором можно записывать свои рецепты:
название, ингредиенты и пошаговые этапы приготовления — каждый этап с фотографией.

Приложение задумано для тех, кто только учится готовить: никаких лишних деталей,
крупные понятные кнопки и явные действия — ничего не сохраняется «само по себе».

---

## Что умеет

- 📋 Список всех сохранённых рецептов на главном экране
- ➕ Создание рецепта: название, обложка, список ингредиентов
- 👣 Пошаговые этапы приготовления, к каждому можно прикрепить фото
- ✏️ Редактирование рецепта: название, ингредиенты, порядок и содержание этапов
- 🗑️ Удаление рецепта с подтверждением
- 🌍 Интерфейс на русском и английском языках
- 📴 Работает полностью офлайн — данные хранятся только на телефоне

---

## Технологии

| Слой | Технология |
|------|-----------|
| Оболочка | [Tauri v2](https://tauri.app) (Android) |
| Интерфейс | React + TypeScript + Vite |
| Ядро | Rust |
| Хранение данных | SQLite (локально на устройстве) |
