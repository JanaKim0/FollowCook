# 🥄 FollowCook

Мобильное приложение для Android, в котором можно записывать свои рецепты:
название, ингредиенты и пошаговые этапы приготовления — каждый этап с фотографией.

Приложение сделано для тех, кто только учится готовить: никаких лишних деталей,
крупные понятные кнопки и явные действия. Ничего не сохраняется «само по себе» —
пока не нажата кнопка, ничего не записано.

---

## Что умеет

- 📋 Список всех рецептов на главном экране, свежие — сверху
- ➕ Создание рецепта: название, фото блюда, список ингредиентов
- 👣 Пошаговые этапы приготовления, к каждому можно прикрепить фото
- ✏️ Редактирование: название, ингредиенты, порядок и содержание этапов
- 🗑️ Удаление рецепта — только с подтверждением, и в вопросе названо само блюдо
- 🌍 Интерфейс на русском и английском, выбор сохраняется
- 📴 Работает полностью офлайн: данные хранятся только на телефоне

---

## Как установить на телефон

### ⬇️ [Скачать FollowCook.apk](https://github.com/JanaKim0/FollowCook/releases/latest/download/FollowCook.apk)

1. Откройте ссылку выше прямо на телефоне.
   Браузер предупредит, что такие файлы могут навредить устройству —
   это обычное предупреждение для приложений не из Play Маркета,
   нажмите «Всё равно скачать».
2. Откройте скачанный файл.
3. Android спросит разрешение на установку из неизвестных источников —
   его нужно дать один раз (это обычное дело для приложений не из магазина).
4. Готово, приложение появится на экране.

> Рецепты хранятся только на самом телефоне и никуда не отправляются.
> Если удалить приложение, рецепты удалятся вместе с ним.

## Как всё устроено

| Слой | Технология |
|------|-----------|
| Оболочка | [Tauri v2](https://tauri.app) (Android) |
| Интерфейс | React 19 + TypeScript + Vite |
| Ядро | Rust |
| Рецепты | SQLite на устройстве |
| Фотографии | Файлы в личной папке приложения |

Несколько решений, которые стоит пояснить:

- **Палитра взята из логотипа.** Мятный `#B2E9C9` — заливка белочки,
  тёмный `#343C3F` — её контур. Поэтому тёмные кнопки не выглядят чужими
  среди светлых тонов и не дают им расплыться.
- **Фотографии сжимаются перед сохранением** до 1400 px и пережимаются
  в JPEG. Снимок с телефона весит мегабайты, а на экране рецепта
  показывается в пару сантиметров.
- **Снимки разворачиваются по метке EXIF** — иначе фото с телефона
  оказывается лежащим на боку.
- **Ингредиенты и этапы — отдельные строки в базе**, а не один текст.
  Только так их можно менять местами и удалять по одному.
- **Экраны не знают, где лежат данные.** Они работают через общий
  интерфейс `RecipeStore`. На телефоне за ним SQLite, а при разработке
  в браузере — запасная реализация на `localStorage`.
- **Словарь задаёт русский файл**, английский обязан повторить его форму.
  Забыть перевести строку не выйдет — проект просто не соберётся.

## Разработка

Нужны Node.js 20+, Rust, JDK 17, Android SDK и NDK.

```bash
npm install
```

Посмотреть интерфейс в браузере — быстро, без сборки под Android:

```bash
npm run dev
```

Собрать `.apk` (скрипт сам найдёт SDK, NDK и Java и ничего не поменяет
в системных настройках):

```bash
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

Готовый файл появится в папке `release/`. Сборка идёт под `arm64-v8a`
и `armeabi-v7a` — это все настоящие телефоны, x86 бывает только
у эмуляторов.

> **Почему сборка не в одну команду.** Tauri раскладывает собранные
> библиотеки по папкам Android-проекта через символические ссылки,
> а Windows разрешает их создавать только в режиме разработчика.
> Скрипт копирует библиотеки сам и запускает Gradle напрямую, поэтому
> работает при любых настройках системы. Если предпочитаете штатный путь
> `npm run android:build` — включите **Параметры → Система →
> Для разработчиков → Режим разработчика**.

Запустить приложение на подключённом телефоне с живой перезагрузкой:

```bash
npm run android:dev
```

### Про подпись приложения

Скрипт собирает библиотеки в **релизном** режиме (7,8 МБ против 161 МБ
у отладочных), а упаковывает их как **debug**-сборку: она подписана
стандартным ключом разработчика, поэтому файл сразу ставится на телефон
и его можно просто переслать близким. Итоговый `.apk` — около 20 МБ.

Для публикации в Google Play нужна релизная сборка со своим ключом:
создайте хранилище ключей через `keytool`, пропишите его в
`src-tauri/gen/android/keystore.properties` и соберите
`npm run android:build`. Ключ и пароли в репозиторий не добавляйте —
они уже перечислены в `.gitignore`.
